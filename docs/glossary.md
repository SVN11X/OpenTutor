# Glossary

The shared language of this project. Use these terms exactly, in code and in conversation. The second column holds the word the owner uses, so a request in another language maps to the right term.

| Term | Owner's word | Means here | Does not mean |
|------|--------------|------------|---------------|
| question set | tareas que se ejecutan, preguntas de GCP | What the quizzes ask: the bank, its source and the chosen exam domains, set in Ajustes under "Qué te pregunto". | A practical task of the Tareas tab. |
| practical task | tarea (pestaña Tareas) | A task written by hand with a file handed in as evidence and a short defense. | A quiz. |
| insistent window | ventana molestosa | The quiz window that stays on top and comes back until all five questions are answered. | A window that blocks other apps or the tray menu. |
| all-day mode | todo el día, segundo plano | A session with no 60-minute limit that starts at sign-in when autostart is on. | A Windows service. |
| eligible time | contador de tiempo | Seconds of real activity inside a session, outside pauses, locks and suspension. | Wall-clock time. |
| spaced repetition | repaso espaciado | Choosing questions so wrong answers return sooner and right ones later. | Never repeating a question. |
